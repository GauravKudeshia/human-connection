# Production remains closed

V1.3 Release A is an interactive simulator. It accepts no real money, connects no real people and has no staffed safety operation. A built button, balanced demo journal or passing local test is not evidence of a live integration.

## Explicit prototype limitations

- Browser state, clock and code are controlled by the visitor; a determined visitor can tamper with them. Demo guards are not a security boundary for real funds. Normal reloads and retries cannot restart a reservation or duplicate its refund.
- Automatic expiry is evaluated on reads/actions and periodic UI refresh while open. A closed tab runs no background worker. On reopening persisted state, overdue reservations are expired before any new action. The server also checks expiry transactionally on access; a production background reconciler is still required.
- sessionStorage normally isolates tabs, but a duplicated/opened tab can begin with a browser-provided copy. It never becomes a globally synchronized pool. Clearing browser data loses public-demo activity. Restricted storage falls back to memory and loses state on reload.
- The server’s optimistic write protects one owner workspace, not a shared marketplace. Public role previews do not implement staff authorization.
- Demo feedback is untrusted text rendered through React. There is no user upload or HTML-rendering feature. Input lengths and relationships are checked; production abuse/rate/retention policies still require implementation.
- Replay records contain SHA-256 comparison digests instead of duplicated narratives. This is data minimization, not encryption or anonymization. The actual feedback remains in its intended demo record until closure/reset.
- Existing financially inconsistent historical demo journals are not rewritten. The new rules apply going forward; old non-delivery ratings are preserved as separate legacy feedback. Production data remediation would require a reviewed reconciliation plan.
- The build uses the existing Vinext starter and dependency baseline. A full dependency advisory/security review, cross-browser certification and penetration test were not completed in Release A.
- External Google Fonts are optional; browser/system fallbacks work without them. Stock portraits are illustrations of fictional characters, not enrolled hosts.

`lib/demo-policy.mjs` keeps live payment, live-call and staffed-safety capabilities false. The engine rejects non-demo runtime modes and unknown provider operations. No configuration toggle in this iteration can turn the simulator into a production provider integration.
